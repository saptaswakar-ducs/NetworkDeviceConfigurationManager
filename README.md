# YANG Network Device Configuration Manager

A beginner-level Python project for managing network device
configuration using a YANG data model.

## Features

- Create network devices
- Read network device configuration
- Update network devices
- Delete network devices
- YANG-based configuration modeling
- JSON-based local storage

## Technologies

- Python
- YANG
- JSON
- pyang
